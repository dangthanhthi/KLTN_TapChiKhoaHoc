II. YÊU CẦU MÔI TRƯỜNG:
--------------------------------------------------------------------------------
- Hệ điều hành: Windows 10 / Windows 11.
- Nền tảng phát triển: Visual Studio 2022 (hoặc .NET 8.0 SDK trở lên).
- Cơ sở dữ liệu: Microsoft SQL Server 2016 trở lên (hoặc LocalDB / SQL Express).


III. HƯỚNG DẪN CÀI ĐẶT CƠ SỞ DỮ LIỆU:
--------------------------------------------------------------------------------
1. Mở SQL Server Management Studio (SSMS).
2. Mở file script:
   `QL_TapChi_WinForms\Database\QL_TapChiKhoaHoc.sql` (hoặc `web_source\SQLKLCN.sql`).
3. Nhấn phím F5 (hoặc nút Execute) để chạy toàn bộ script.
   Script sẽ tự động tạo CSDL `QL_TapChiKhoaHoc` cùng toàn bộ bảng, khóa chính/ngoại,
   ràng buộc kiểm tra và nạp sẵn bộ dữ liệu mẫu đầy đủ.


IV. HƯỚNG DẪN CHẠY ỨNG DỤNG:
--------------------------------------------------------------------------------
Cách 1: Chạy trực tiếp từ Visual Studio
1. Mở file `QL_TapChi_WinForms\QL_TapChi_WinForms.csproj` bằng Visual Studio 2022.
2. Chọn cấu hình Debug hoặc Release (x64 / Any CPU).
3. Nhấn phím F5 để bắt đầu chạy.

Cách 2: Chạy trực tiếp từ file thực thi đã biên dịch
- Vào thư mục: `QL_TapChi_WinForms\bin\Debug\net8.0-windows\`
- Nhấp đúp vào file `QL_TapChi_WinForms.exe`.
